
# 📖 Alizubu Quote Maker

A simple and stylish quote maker web app that lets users generate, customize, and share beautiful quotes easily. Built with modern web technologies for a smooth and responsive experience.

---

## ✨ Features

* 🎨 Beautiful quote card design
* 📝 Add custom quotes and author names
* 📱 Fully responsive UI
* ⚡ Fast and lightweight
* 📋 Copy quote functionality
* 📸 Download quote as image *(if available)*
* 🌙 Clean modern interface

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/alizubu/alizubu-quote-maker.git
```

Go to the project folder:

```bash
cd alizubu-quote-maker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
